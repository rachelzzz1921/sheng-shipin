# 画风对照

场景实现在 `vendor/huashu-art-motion`，只读。质量和短板摘自该仓库 `references/风格配方/INDEX.md`（2026-10-05）。缺 id 的不要新写渲染器。

需要贴进画面、代码画不好的东西，用这一支分镜的生图提示词，不用花叔的角色帧。背景仍用下表的场景。

| 片子里要的感觉 | 花叔 id | 质量 | 用的时候注意 |
| --- | --- | --- | --- |
| 软钟、液滴、事物在融化 | `23_dali` | ★★ | 花叔原片人物偏矢量插画，主体改用这一支的透明图 |
| 墨晕、留白、一笔扫开 | `17_ink` | ★★ | 花叔原片人物不够写意，主体改用这一支的透明图 |
| 红黄蓝几何、层级、节拍 | `12_bauhaus` | ★★★ | 可直接用几何构成 |
| 画面被拉弯、追一个够不到的东西 | `19_munch` | ★★ | 墙面容易被看成梵高，静帧里要看得出是扭曲而不是漩涡 |
| 红黑斜线、大字盖章、镜头拉开 | `22_constructivism` | ★★★ | 适合反转前后的硬切感觉，转场仍要遵守 shape-morph |
| 黑底大字、印章砸下来 | 无单独场景 | — | 用 prompt-motion 的 `kinetic-type`，不要发明新渲染器。几何底可借 `12_bauhaus` 或 `16_2026` |
| 当代扁平、无描边 | `16_2026` | ★★★ | 结尾留白、门和钥匙 |

其他 35 种里，只有分镜表写明了 id 才能用。梵高是 `09_postimp`，不是默认风格。
